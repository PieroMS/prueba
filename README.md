# Mini E-commerce - Ropa
Este proyecto es una **app básica de e-commerce** enfocada en ropa. Solo incluye dos vistas principales:

- 🏠 **Inicio**: una maqueta visual de la tienda con productos simulados.
- 🔐 **Login**: un formulario simple de inicio de sesión.

## 📌 Notas

- Este proyecto es solo una **maqueta estática**.
- No cuenta con funcionalidades reales como carrito, backend o gestión de productos.
- No es responsive (no se adapta a móviles o pantallas pequeñas).
